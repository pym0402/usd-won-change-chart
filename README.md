# 원 달러 환율 차트 앱

1999-2006년 원/달러 환율 데이터를 시각화하는 웹 애플리케이션입니다.

## 기능

- 1999-2006년 원/달러 환율 데이터 시각화
- 시간 범위 선택기 (1년, 5년, 10년, 최대)
- 인터랙티브 툴팁 (날짜 및 환율값 표시)
- 반응형 디자인
- 결측치(0값) 자동 필터링

## 기술 스택

- **백엔드**: Node.js, Express
- **프론트엔드**: 바닐라 JavaScript (HTML/CSS/JS)
- **차트 라이브러리**: Chart.js (CDN)
- **데이터 처리**: Node.js fs 모듈

## 설치 방법

1. Node.js가 설치되어 있는지 확인합니다.
2. 프로젝트 디렉토리에서 의존성을 설치합니다:
   ```bash
   npm install
   ```

## 실행 방법

1. 서버를 시작합니다:
   ```bash
   npm start
   ```
2. 브라우저에서 http://localhost:3000 접속합니다.

## API 엔드포인트

- `GET /api/exchange-rates`: 환율 데이터를 JSON 형식으로 반환

## 데이터 소스

- 데이터 파일: `docs/usd2won.csv`
- 데이터 기간: 1999-01-04 ~ 2006-11-07
- 총 데이터 포인트: 약 2000개

## 주의사항

- 주말/공휴일의 0값은 차트에서 자동으로 제외됩니다
- 대용량 데이터이므로 성능 최적화가 적용되어 있습니다
- 시간 범위 선택기는 데이터 필터링 후 차트를 업데이트합니다
