# 원 달러 환율 차트 앱 명세

## 프로젝트 개요
- **앱 제목**: 원 달러 환율
- **목적**: 1999-2006년 원/달러 환율 데이터를 시각화하는 웹 애플리케이션
- **데이터 소스**: docs/usd2won.csv (1999-01-04 ~ 2006-11-07)

## 기술 스택
- **백엔드**: Node.js
- **프론트엔드**: 바닐라 JavaScript (HTML/CSS/JS)
- **차트 라이브러리**: Chart.js (CDN 방식)
- **데이터 처리**: Node.js fs 모듈로 CSV 파싱

## 데이터 처리 방법
- CSV 파일 구조: `observation_date,usd2won,`
- 결측치 처리: 환율값이 `0`인 행은 차트에서 제외
- 날짜 형식: YYYY-MM-DD
- 환율값: 소수점 2자리까지 (예: 1417.44)

## 차트 구현 사양
- **차트 타입**: Line Chart (선 그래프)
- **X축**: 날짜 (observation_date)
- **Y축**: 환율값 (usd2won)
- **차트 제목**: "원 달러 환율 추이"
- **반응형**: 웹 브라우저 크기에 따라 자동 조정

## 추가 기능 사양

### 시간 범위 선택기
- **형태**: 버튼 형태의 시간 범위 선택기
- **옵션**: 1년, 5년, 10년, 최대
- **기본값**: 최대 (전체 데이터)
- **동작**: 버튼 클릭 시 해당 기간의 데이터만 차트에 표시
- **위치**: 차트 상단 또는 하단

### 인터랙티브 툴팁
- **트리거**: 마우스 오버 시 표시
- **표시 형태**: 수직 십자선과 함께 툴팁 표시
- **툴팁 내용**: 날짜 + 환율값 동시에 표시
- **위치**: 마우스 포인터 근처 또는 차트 상단 고정

## 개발 환경 설정
- Node.js 설치 필요
- npm으로 Express 설치: `npm install express`
- 브라우저에서 로컬 서버 접속: http://localhost:3000

## 주의사항
- CSV 파일의 콤마로 끝나는 형식 처리 필요
- 주말/공휴일의 0값은 차트에서 제외
- 날짜 데이터는 Chart.js에서 적절히 포맷팅 필요
- 대용량 데이터(약 2000행)이므로 성능 고려
- 시간 범위 선택기는 데이터 필터링 후 차트 업데이트 필요
- 툴팁은 Chart.js 플러그인 설정으로 구현
