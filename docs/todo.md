# 원 달러 환율 차트 앱 구현 체크리스트

## Phase 1: 프로젝트 초기화

- [x] **package.json 생성**
  - **인수기준**: Node.js 프로젝트용 package.json 파일이 존재하고, 이름, 버전, 스크립트가 정의되어 있어야 함
  - **검증**: `npm install` 실행 시 에러 없이 완료되어야 함

- [x] **public 디렉토리 생성**
  - **인수기준**: public/ 디렉토리가 존재해야 함
  - **검증**: `ls public` 명령어로 디렉토리 확인 가능

- [x] **Express 설치**
  - **인수기준**: package.json에 express 의존성이 추가되어야 함
  - **검증**: `npm install` 후 node_modules/express/ 디렉토리 존재

## Phase 2: 백엔드 기본 구조

- [x] **기본 Express 서버 구현**
  - **인수기준**: server.js 파일이 존재하고, 기본 Express 서버가 3000번 포트에서 실행되어야 함
  - **검증**: `node server.js` 실행 시 "Server running on port 3000" 메시지 출력

- [x] **정적 파일 서빙 설정**
  - **인수기준**: public/ 디렉토리의 정적 파일이 서빙되어야 함
  - **검증**: 브라우저에서 http://localhost:3000/index.html 접근 시 파일 로드됨

## Phase 3: 프론트엔드 기본 구조

- [x] **기본 HTML5 구조 생성**
  - **인수기준**: public/index.html 파일이 존재하고, HTML5 기본 구조를 가져야 함
  - **검증**: 브라우저에서 HTML 파일이 정상적으로 렌더링됨

- [x] **앱 제목 표시**
  - **인수기준**: 페이지에 "원 달러 환율" 제목이 표시되어야 함
  - **검증**: 브라우저에서 제목이 보이는지 확인

- [x] **Chart.js CDN 포함**
  - **인수기준**: HTML 파일에 Chart.js CDN이 포함되어야 함
  - **검증**: 브라우저 개발자 도구에서 Chart 객체가 로드된 것을 확인

- [x] **차트 캔버스 요소 추가**
  - **인수기준**: HTML에 canvas 요소가 존재하고 차트를 위한 ID가 할당되어야 함
  - **검증**: HTML에서 `<canvas id="exchangeChart"></canvas>` 요소 존재

- [x] **시간 범위 선택기 버튼 그룹 추가**
  - **인수기준**: 1년, 5년, 10년, 최대 버튼이 그룹으로 추가되어야 함
  - **검증**: HTML에 4개의 버튼 요소가 존재하고 각각의 data-period 속성이 있어야 함

## Phase 4: 데이터 처리

- [x] **CSV 파일 읽기 기능 구현**
  - **인수기준**: Node.js fs 모듈을 사용하여 CSV 파일을 읽을 수 있어야 함
  - **검증**: 서버 콘솔에 CSV 파일 내용이 출력됨

- [x] **CSV 파싱 기능 구현**
  - **인수기준**: CSV 데이터를 파싱하여 날짜와 환율값을 추출할 수 있어야 함
  - **검증**: 파싱된 데이터가 JSON 형식으로 변환되어야 함

- [x] **결측치(0값) 필터링 로직 구현**
  - **인수기준**: 환율값이 0인 데이터를 필터링해야 함
  - **검증**: 필터링 후 환율값이 0인 데이터가 없어야 함

- [x] **API 엔드포인트 생성 (/api/exchange-rates)**
  - **인수기준**: GET /api/exchange-rates 엔드포인트가 존재하고 JSON 데이터를 반환해야 함
  - **검증**: curl 또는 브라우저로 접근 시 JSON 데이터 반환됨
